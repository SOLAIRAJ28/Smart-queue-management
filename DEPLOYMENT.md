# Deployment Guide - Smart Queue Management System

This document outlines the three primary ways to host and run the Smart Queue Management System: **Locally**, using **Docker Containers**, or on the **Render Cloud Platform**.

---

## Option 1: Local Hosting (Development / Manual Setup)

This is best for local development, testing, and modifications.

### 1. Prerequisites
- **Node.js** (v18 or higher)
- **MongoDB** (Local instance or MongoDB Atlas account)

### 2. Configure Environment Variables
You need configuration for both the frontend and the backend.

- **Backend environment config** (`server/.env`):
  ```ini
  PORT=5000
  MONGODB_URI=your_mongodb_connection_uri
  JWT_SECRET=your_jwt_access_secret
  JWT_REFRESH_SECRET=your_jwt_refresh_secret
  ```

- **Frontend environment config** (`.env`):
  ```ini
  VITE_API_URL=http://localhost:5000/api
  ```

### 3. Run the Services
You need to start the backend and frontend in separate terminals.

- **Start Backend**:
  ```bash
  cd server
  npm install
  npm run dev
  ```

- **Start Frontend**:
  ```bash
  npm install
  npm run dev
  ```
  Open `http://localhost:5173` to access the application.

---

## Option 2: Docker Containerization (On-Premise / Self-Hosted Server)

This is the easiest way to launch the entire stack (Database, Backend API, and Frontend web server) in a single command, ensuring containerized isolation.

### 1. Prerequisites
- **Docker** and **Docker Compose** installed.

### 2. Run Docker Compose
In the root directory of the project, run:
```bash
docker-compose up --build
```

This will automatically pull the MongoDB image, compile the production assets for the frontend (served via Nginx), build the Express backend, and spin up the network.

- Frontend URL: `http://localhost`
- Backend API URL: `http://localhost:5000`

---

## Option 3: Cloud Hosting (Render Platform)

This project has been preconfigured for Render using **Render Blueprints** (`render.yaml`). This spins up both services automatically.

### 1. Prerequisites
- A GitHub repository containing this codebase.
- A **Render** account linked to your GitHub.
- A **MongoDB Atlas** database URI.

### 2. Deploy Using Render Blueprint
1. Go to [Render Dashboard](https://dashboard.render.com).
2. Click **Blueprints** in the top navigation menu.
3. Click **New Blueprint Instance**.
4. Select your `Smart-queue-management` repository.
5. Render will automatically parse the `render.yaml` file and request:
   - **`MONGODB_URI`**: Your MongoDB connection string.
   - **`JWT_SECRET`** and **`JWT_REFRESH_SECRET`**: (Auto-generated by Render securely).
6. Click **Apply** to deploy.

Render will start building and hosting:
1. **Express Server (Web Service)**: Accessible at `https://smart-queue-backend.onrender.com`.
2. **React Client (Static Site)**: Accessible at `https://smart-queue-frontend.onrender.com`.
